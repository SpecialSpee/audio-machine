# █ АУДИО-МАШИНА // КОНВЕРТЕР

Десктопное приложение для пакетной конвертации аудиоформатов в стиле советского конструктивизма.

## ▌ ВОЗМОЖНОСТИ
- **FLAC → WAV**: Конвертация с выбором битности (PCM_16, PCM_24, FLOAT).
- **WAV → MP3**: Сжатие с выбором битрейта (128k, 192k, 256k, 320k).
- **GUI**: Интерфейс в стиле конструктивизма (PyQt6), асинхронная обработка без зависаний.
